# WIKELO

A trader's-emporium reference for **Star Citizen's** Banu trader *Wikelo*. Browse what he sells, what he'll trade for, the reputation tracks, and plan the materials you need to bring.

Live site: [seeknd.github.io/Wikelo](https://seeknd.github.io/Wikelo)

---

## Features

### Items & Recipes
Every item Wikelo offers — armor sets, weapon skins, gear — with the full list of materials and quantities required to obtain each one. Filter by category, search by name.

### Ships & Vehicles
Ship modifications, components, and ATLS variants available through Wikelo, with their material costs.

### Currency
How *Wikelo Favors* (his trade currency) are earned, the exchange ratios for every material he accepts, and which materials give the best Favor-per-aUEC return.

### Inventory Planner
Enter the materials you already have. The planner shows what you're close to redeeming, what you're missing, and produces a shopping list of what to gather next.

### Reputation
Every reputation track with its tiers, the missions that grant reputation, and the rewards unlocked at each tier.

---

## Data

The site loads a single `wikelo_data.json` at startup containing every item, recipe, ship modification, currency exchange ratio, and reputation track for the current patch. This file is updated each patch.

All user data (inventory, settings) is stored in your browser's local storage — nothing is sent to a server.

---

## Tech

Pure static site — HTML, CSS, vanilla JS. No frameworks, no build tools, no server. Hosted on GitHub Pages.
